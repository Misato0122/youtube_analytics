今すぐ取得の設定

毎日のデータは自動で集めています（日本時間 7時・19時ごろ）。
「今すぐ取得」を使うと、この端末から最新の急上昇をその場で取得できます。そのためには YouTube Data API のキーが必要です。

キーはこの端末のブラウザの中だけに保存され、ほかには送られません（YouTube への問い合わせにだけ使います）。
キーは Google Cloud Console の「認証情報」で、使えるサイトをこのアプリの URL に制限しておくと安全です。
